## Цель
AI-ассистент для консультации клиентов по продуктам ТехноРэд (REDWELD, REDLOAD, REDCARGO, REDEDUCATION). Помогает менеджерам и клиентам быстро находить нужные модели, характеристики, применимость.

## Архитектура (актуальная)

```
START (sys.query + conversation history)
    ↓
LLM-0: КЛАССИФИКАТОР / ПЕРЕФРАЗИРОВЩИК
  — нужен ли поиск по БЗ?
  — разрешает анафорические ссылки (он/она/эта модель → конкретная модель)
  — выдаёт: need_search (bool) + rewritten_query (str)
    ↓
Python Code Block (парсит JSON от LLM-0)
    ↓
IF/ELSE: need_search?
  ├── YES → Knowledge Retrieval (rewritten_query) → LLM-1 (ответ с контекстом БЗ)
  └── NO  → LLM-2 (ответ из истории диалога без поиска)
    ↓
OUTPUT
```

## Поиск
- Режим: гибридный — Dense (Cohere) + BM25, баланс 0.6 / 0.4
- Top K: 6
- Score Threshold: 0.3
- Embeddings: Cohere embed-multilingual-v3.0 (OpenRouter не поддерживает embeddings — Cohere напрямую)

## Источники данных в БЗ
- Каталог продуктов: Excel (12 листов, 161 запись) → Markdown + CSV
- Документация REDWELD: DOCX (предпочтительный формат), конвертированная из PDF
- Форматы в БЗ: DOCX, MD, CSV (PDF и XLSX не использовать — плохо чанкуются)

## Чанкинг
- Размер чанка: 512 символов
- Каждый продукт — единый плотный текстовый блок с одинарными переносами (\n) внутри
- Разделитель между продуктами: \n\n (двойной — чтобы чанкер резал между, а не внутри записи)
- Изображения в MD: заменяются на текстовые плейсхолдеры [ИЗОБРАЖЕНИЕ: описание]

## Баги Dify — задокументированные и решённые
| Баг | Решение |
|-----|---------|
| sys.conversation_history недоступен через шаблон | Использовать встроенный Memory (window size 10) |
| Python Code Block: имя параметра функции | Должно точно совпадать с именем input-переменной в настройках блока (arg1) |
| Input variable source в LLM-0 | Указывать на поле .text вывода LLM, не на reasoning_content |
| Output из Code Block | Возвращать как плоский словарь (top-level keys), не вложенный в result |
