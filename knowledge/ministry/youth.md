## О служении
Молодёжное служение «(НЕ)ОДИН» при церкви Ассамблеи Бога Одинцовского г.о.
Охват: Одинцово, Звенигород, Жаворонки.

### Смысл названия
- Географический: «Один» → Одинцово
- Экзистенциальный: ты не один
- Богословский: Бог с тобой (Ин. 14:18, Мф. 28:20)
- Общинный: есть сообщество
- Типографический: скобки (НЕ) — провокация, вопрос, визуальный якорь

## Инструменты и активности

### Карточная игра (Матрёшка-формат)
Три колоды по 30 карточек (90 карточек, 270 вопросов), три уровня на карточку (зелёный → жёлтый → красный):
- **Ледокол** — для любой компании, без религиозного контекста
- **Мост** — для смешанных групп с неверующими, мягкий выход на вопросы веры
- **Глубина** — для молодёжки, темы: Библия, молитва, духовные дары, сомнения

Реализация: web-приложение (single-file index.html), хостинг GitHub Pages.
Функции: свайп-навигация, тёмная тема, localStorage, перемешивание карточек (Fisher-Yates), прогресс-бар.

### Пост и молитва (предпятидесятница)
4-дневная серия: карточки-темы для Instagram, формат devotional.
Темы: Жажда / Святой Дух как друг / Крещение Духом / Замысел Бога.
Оформление: карточки 1080×1080, HTML + html2canvas, 4 цветовые темы.

### Встречи и повестки
Создаём структурированные повестки и отчёты встреч (DOCX + Telegram plain text).
Разделы: план на сезон, дела в работе, открытые вопросы, задачи с дедлайнами.
