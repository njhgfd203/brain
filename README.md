# Brain — личный AI-ассистент в Telegram

Self-hosted ассистент: хранит заметки в Markdown, ищет по ним семантически (RAG), отвечает с контекстом через Claude, ведёт задачи с дедлайнами. Всё на своём VPS, без SaaS.

Подробный контекст проекта и архитектура — в [`CLAUDE.md`](./CLAUDE.md).

---

## Что понадобится

### 1. Секреты (обязательно)

| Что | Где взять |
|-----|-----------|
| **Telegram bot token** | [@BotFather](https://t.me/BotFather) → `/newbot` → задай имя и username → получишь токен вида `123456789:AAÉ...` |
| **Свой Telegram user_id** | Напиши [@userinfobot](https://t.me/userinfobot) — пришлёт твой числовой `id`. Только этот пользователь сможет общаться с ботом |
| **OpenRouter API key** | [openrouter.ai](https://openrouter.ai) → зарегистрируйся → **Keys** → создай ключ. **Важно: пополни баланс** — модель `claude-sonnet-4-5` платная (оплата по факту использования) |

### 2. Инфраструктура

- **VPS** (любой Linux) с установленными **Docker** и **docker compose**.
- Диск: образ тяжёлый (~несколько ГБ) — `sentence-transformers` тянет `torch`. Заложи 5–10 ГБ свободного места.

### 3. Только для режима `webhook` (опционально)

Если выберешь `BOT_MODE=webhook`, дополнительно нужны:
- **доменное имя**, указывающее на IP VPS;
- **HTTPS-сертификат** (Telegram шлёт апдейты только на HTTPS). Бот слушает обычный HTTP на `:8443`, поэтому нужен **reverse-proxy** (Caddy / nginx) с Let's Encrypt, который терминирует TLS и проксирует на бота.

> **Рекомендация:** для старта используй `BOT_MODE=polling` — тогда домен, сертификат и проброс портов **не нужны вообще**. Бот сам опрашивает Telegram и работает 24/7. На webhook можно перейти позже — код это уже поддерживает.

## Установка и запуск

```bash
# 1. Склонировать на VPS
git clone <repo> brain && cd brain

# 2. Создать .env из примера
cp .env.example .env

# 3. Заполнить .env (см. ниже)
nano .env

# 4. Запустить
docker compose up -d

# 5. Посмотреть логи
docker compose logs -f bot
```

### Заполнение `.env`

Минимум для режима **polling**:

```bash
TELEGRAM_BOT_TOKEN=123456789:AAÉ...      # от @BotFather
BOT_MODE=polling                          # ← polling, домен не нужен
TELEGRAM_ALLOWED_USER_ID=123456789        # твой id от @userinfobot
OPENROUTER_API_KEY=sk-or-...              # от openrouter.ai (с балансом!)
```

Для режима **webhook** дополнительно:

```bash
BOT_MODE=webhook
TELEGRAM_WEBHOOK_URL=https://yourdomain.com/webhook
```

Остальные переменные (пути, модель, настройки RAG) уже имеют рабочие значения по умолчанию — менять не обязательно.

## Первый запуск

1. После `docker compose up -d` напиши боту `/start` — он ответит списком команд.
2. **Первый `/ask` или `/reindex` будет медленным** (30–90 сек): при первом обращении скачивается модель эмбеддингов e5-base (~1 ГБ). Дальше — быстро.
3. Положи свои заметки в `knowledge/` (домены `technored/`, `ministry/`, `personal/`) и выполни `/reindex`, чтобы проиндексировать их. Заметки через `/note` индексируются автоматически.

---

## Команды

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и список команд |
| `/note <текст>` | Сохранить заметку в `knowledge/inbox/YYYY-MM-DD.md` (сразу индексируется) |
| `/ask <вопрос>` | Поиск по базе знаний + ответ Claude. Можно просто написать текст без команды |
| `/task <текст> [когда] [#домен]` | Добавить задачу. См. примеры ниже |
| `/today` | Задачи на сегодня + просроченные |
| `/week` | Обзор задач на 7 дней по доменам |
| `/reindex` | Переиндексировать всю папку `knowledge/` |

### Примеры `/task`

```
/task позвонить подрядчику завтра
/task #technored дедлайн по REDWELD в пятницу
/task купить подарок 2026-06-20
/task #ministry подготовить материалы для встречи
```

- **Дата** распознаётся из текста (рус. язык): «завтра», «в пятницу», «через 3 дня», `ГГГГ-ММ-ДД`. Лучше писать полные формы («в пятницу», а не «пт») — сокращения распознаются хуже. Без даты задача создаётся «без срока».
- **Домен** — необязательный тег `#technored` / `#ministry` / `#personal`. По умолчанию `personal`.

## Данные и бэкап

Всё хранится локально и переживает перезапуск контейнера:

| Данные | Где |
|--------|-----|
| Заметки (Markdown) | `./knowledge/` |
| Задачи (SQLite) | `./db/brain.sqlite` |
| Векторный индекс | Docker volume `chroma_data` |

Для бэкапа достаточно сохранить `knowledge/` (можно держать в git) и `db/`. Векторный индекс восстанавливается из заметок через `/reindex`.

## Режимы запуска

Переключается переменной `BOT_MODE` в `.env`:

- **`polling`** — бот сам опрашивает Telegram. Ничего, кроме секретов, не нужно. Рекомендуется для старта.
- **`webhook`** — Telegram шлёт апдейты на твой HTTPS-эндпоинт. Нужны домен + TLS (reverse-proxy). Бот слушает `:8443`.
